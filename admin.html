How do I get an access token?
  1. Sign in to GitHub, click your photo → Settings.
  2. Scroll down on the left to Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Give it any name. Set Expiration to the longest you can.
  4. Under "Repository access" choose Only select repositories and pick your website repository.
  5. Under Permissions → Repository permissions, set Contents to Read and write.
  6. Click Generate token, copy it and paste it above. GitHub shows it only once.

Anyone who opens this page still cannot change your website without the token. Do not share the token.
