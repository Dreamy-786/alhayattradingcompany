Only for the stock keeping section. Leave empty if you have not set it up yet. The Stock tab shows how.

How do I get an access token?
  1. Sign in to GitHub, click your photo, then Settings.
  2. Scroll down on the left to Developer settings, then Personal access tokens, then Fine-grained tokens, then Generate new token.
  3. Give it any name and set Expiration to the longest you can.
  4. Under "Repository access" choose Only select repositories and pick your website repository.
  5. Under Permissions, Repository permissions, set Contents to Read and write.
  6. Click Generate token and paste it above. GitHub shows it only once. Never share it with anyone.

Product photos

Photos can be JPG, PNG, WebP or AVIF. They are made square with white borders so every product card looks the same, and saved in the images folder of your repository. The first photo is the main one. A photo on a flavour row shows when that flavour is picked.

Home page rows

These are the sideways rows on your homepage. Choose which products show in each row and in what order. Customers can tap See all to open the full row. Untick Show to hide a row. A row with no products is hidden automatically.

Share links

Every product has its own link, like your-site/p/1/. When someone opens it, they see that product with photos, sizes and prices. For a nice picture preview when the link is pasted in WhatsApp, a small page is created for each product. This happens automatically when you save a product. Press the button once now so your existing products get one too.

Stock keeping setup

Your stock records are kept in a second, private repository so nobody can see them on the internet. One time setup:

  1. Open github.com/new. Repository name: alhayat-stock. Select Private. Tick Add a README file. Press Create repository.
  2. Open github.com/settings/personal-access-tokens, click your existing token, then Repository access, then Only select repositories and tick alhayat-stock as well. Press Update.
  3. Come back here, press Disconnect, connect again and type alhayat-stock in the last box (Stock repository).
  4. Staff: make another token the same way but tick only alhayat-stock and give it Contents: Read and write. Staff open your-site/staff/ and paste that token.

You can already add products with barcodes and opening stock before this. They are kept safely on this computer and added automatically when this setup is done.

Posters

These slide across the top of your homepage. Best size: wide image about 1600 by 500. Optional phone image: square about 800 by 800 (if every poster has one, phones show the square version). When no poster is added, the normal welcome banner shows.

Add a poster

Category round pictures

Each category shows as a round picture on the homepage. Upload a picture (for example a protein tub for Protein). Tap it on the website and only that category opens. Use the arrows to set the order. Press Save when done.

Brands

Brands are always listed A to Z. Upload each brand logo, an optional banner and a short line about it. Tap a brand on the website and all its products open. Brands come from the brand name you type on products. Press Save when done.
